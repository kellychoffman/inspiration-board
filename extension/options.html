Sign in with an application password instead

By default the extension posts as whoever is signed in to your site in this browser, and stores nothing. Use an application password only if you would rather it work while you are signed out.

  1. Open Users → Profile → Application Passwords on your site and make one named Inspiration Board.
  2. Copy the password WordPress shows you and paste it below. It is stored in this browser's extension storage and sent only to your own site.

Leave both blank to go back to using your browser login.
